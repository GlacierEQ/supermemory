# Integrations

Lightweight integration stubs for external systems described in the
project roadmap. Each module exposes a minimal interface that can be
expanded as the respective services become available.

## Available modules

- **FileBoss** – scanning utilities for the FileBoss evidence store.
- **MEGA-PDF** – helpers for extracting text from legal documents.
- **WhisperX** – audio transcription facades.

The goal of these modules is to provide a clear location for future
expansion while keeping the current codebase lean and testable.
